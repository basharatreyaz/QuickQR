How to get PayPal credentials:

  1. Log in to developer.paypal.com.
  2. Go to Apps & Credentials in dashboard.
  3. Select Sandbox (for testing) or Live (for production).
  4. Click Create App and name it (e.g. QuickQR).
  5. Copy the Client ID and Secret Key into the fields on the left.
  6. Click Test Connection to verify, then Save!
