API Overview

The QuickQR API is organized around predictable RESTful endpoints. All requests communicate over standard HTTPS and accept/return JSON payloads.

Base API URL
http://localhost/sass/api

Authentication

QuickQR supports dual authentication modes: PHP session cookies (for web dashboard sessions) and persistent API secret keys (for programmatic backend integrations).

Pass your secret API key in the HTTP request headers using either X-API-Key or the standard Authorization: Bearer <key>: 

X-API-Key: qk_live_a1b2c3d4e5f67890abcdef123456

You can generate, view, and cycle your API Key anytime inside your Account Settings.

Standard JSON Envelopes

All API responses adhere to a consistent contract. Successful calls return success: true with the data object. Errors return success: false accompanied by machine-readable error codes.

Success Envelope (200 OK)
{
  "success": true,
  "data": { ... },
  "message": "Operation completed"
}
Error Envelope (4xx / 5xx)
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Invalid URL destination"
  }
}
POST /api/qr/create.php

Creates a new dynamic QR code with short-redirect URL, custom hex branding colors, and telemetry tracking.

Request Parameters (JSON Body)

Parameter Type Description
name Required string Human-readable label for the QR campaign (e.g. "Summer Promo")
type Required string Payload type: url, wifi, vcard, email, phone, sms
destination Required string Target URL (must be valid http:// or https://)
config object Design options: fg_color (hex), bg_color (hex), size (px), ecc (L/M/Q/H)

Example cURL Request

curl -X POST http://localhost/sass/api/qr/create.php \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{
    "name": "Product Launch 2026",
    "type": "url",
    "destination": "https://example.com/launch",
    "config": {
      "fg_color": "#4f46e5",
      "bg_color": "#ffffff",
      "ecc": "M"
    }
  }'
GET /api/qr/list.php

Retrieves a paginated list of QR campaigns belonging to the authenticated account. Supports filtering by search keyword and status. 

curl -X GET "http://localhost/sass/api/qr/list.php?page=1&limit=10&status=active" \
  -H "X-API-Key: YOUR_API_KEY"
GET /api/qr/preview.php

Instantly renders a live QR code image in SVG or PNG format. Can be used without authentication for on-the-fly rendering widgets. 

curl -X GET "http://localhost/sass/api/qr/preview.php?destination=https://example.com&format=svg"
GET /api/analytics/stats.php

Returns comprehensive scan telemetry including total scans, unique scanners, daily scan volumes, device distributions (Mobile vs Desktop vs Tablet), operating systems, and country geolocation statistics. 

curl -X GET "http://localhost/sass/api/analytics/stats.php?qr_id=1&days=30" \
  -H "X-API-Key: YOUR_API_KEY"
